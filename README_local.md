#ERP Advocacia

Projeto da disciplina Projeto Interdisciplinar IV.

## Entrega 15/09
- Script DDL + DML em `Scripts/script_erp_advocacia.sql`
- Aplicação Windows Forms em `ERPAdvocacia/`

## Como rodar
1. Execute o script `Scripts/script_erp_advocacia.sql` no MySQL/MariaDB.
2. Abra `ERPAdvocacia.sln` no Visual Studio.
3. Ajuste a senha do MySQL em `Data/ConexaoBD.cs` se necessário.
4. Aperte F5.
